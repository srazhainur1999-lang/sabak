Қай функция тақ? Қайсысы кемиді?

y = arcsin xD = [−1; 1], E = [−π/2; π/2], өседі, тақ

y = arcctg xD = R, E = (0; π), кемиді
Есте сақта

Негізгі тепе-теңдіктер

  • arcsin x + arccos x = π/2; arctg x + arcctg x = π/2
  • arcsin(−x) = −arcsin x; arctg(−x) = −arctg x
  • arccos(−x) = π − arccos x; arcctg(−x) = π − arcctg x
  • cos(arccos x) = x, x ∈ [−1; 1]; arccos x ∈ [0; π]

Детектив

Оқушы былай шығарды:

  1. arccos(−√3/2) = −arccos(√3/2) = −π/6

Арккосинустың мәндер облысы қандай? −π/6 оған жата ма?

  1. arccos тақ функция емес, сондықтан arccos(−x) ≠ −arccos x
  2. Мәндер облысы [0; π], ал −π/6 ∉ [0; π]
  3. Дұрысы: arccos(−x) = π − arccos x
  4. arccos(−√3/2) = π − π/6 = 5π/6

Дұрыс жауабы: 5π/6
